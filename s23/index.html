글자가 사람 뒤로 지나가는 영상, 클로드 코드로 만들기

유튜브에서 보기 ›

요즘 많이 보이는 '글자가 사람 뒤로 지나가는' 말하는 영상을 편집 프로그램 없이 클로드 코드로 만들었습니다(방법 = @prompt_what 가이드). 영상 속 인물과 목소리는 무료 영상 AI LTX-2.5로 만든 가상 인물이고, 편집은 전부 저희 PC에서 무료 도구로 했습니다.

준비물

카메라를 보고 말하는 세로 영상 1개(카메라 고정 · 단색 벽 · 머리 위 여백), 내 컴퓨터 파일을 읽고 실행할 수 있는 클로드 코드. ffmpeg · rembg · Playwright · 받아쓰기 도구는 없으면 클로드 코드가 설치합니다.

요청문 정리(가이드 내용을 저희 말로 줄인 것)

  1. 대사를 받아 적고 단어마다 시작 시각을 표로 만들어. 모든 움직임은 이 시각에 맞춰.
  2. 사람만 오려 내(rembg u2net_human_seg). 원본 → 큰 글자 → 오려 낸 사람 3층으로 겹쳐서 글자가 머리 뒤로 지나가게 해.
  3. 대사 한 줄마다 화면 사건 하나. 얼굴과 입은 가리지 말고, 색 3~4개 · 서체 2개로 통일해.
  4. 장면은 HTML 한 장. window.seek(t) 하나가 t초 화면을 전부 그리게 하고, 타이머 · CSS 애니메이션 · 난수는 쓰지 마.
  5. 전체 렌더 전에 정지 화면 6~8장과 3초 시험 영상부터 보여 줘.
  6. Playwright로 1/24초마다 캡처해서 ffmpeg로 묶고 원본 소리를 합쳐.

너는 모션그래픽 편집자야. talk.mp4 위에 모션그래픽을 얹어서 MP4로 줘.
